# `challenge-solutions`
My solutions to various programming problems/challenges. They are mostly written in Python, but some are in C/C++.

## "Project" Structure
This repository mainly documents my solutions to various programming problems, they mostly are about data structures and algorithms. 

For questions on specific online judges, I have the:
- `leetcode/`
- `uva/`
directories. They group my solutions to the questions that can be found on these online judges. At the top of every file I will put:

```
# ONLINE_JUDGE NUMBER (Python)
// ONLINE_JUDGE NUMBER (C/C++)
```

Some questions, not specific to an online judge, but can be grouped into a topic, are placed under topic-based directories, currently there are:
- `Array-String`: Questions about array/strings
- `Stack-Recursion`: Questions about stack/recursion.

Finally, questions that don't belong to any of them just get a top-level directory.
